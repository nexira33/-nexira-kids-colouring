NEXIRA Digital – Kids Colouring Studio v2

Included:
- 30 free original starter colouring pages across Animals, Vehicles, Nature and Space.
- Touchscreen drawing, colour palette, brush, eraser, undo, clear and PNG save.
- Three premium collection preview cards (not purchasable yet).
- Mobile-responsive layout and basic PWA support.

Preview:
1. Extract the ZIP.
2. Open index.html in a browser.
3. For install/offline support, deploy over HTTPS (e.g. GitHub Pages).
4. iPhone: open deployed site in Safari > Share > Add to Home Screen.

Not yet implemented:
- Razorpay/payment processing or premium access control.
- Advertising.
- Login, cloud save or parental dashboard.
- A production privacy policy / consent workflow.

Because this is intended for children, do not enable ads or collect personal information until child-safety, privacy, consent and applicable advertising requirements have been reviewed.
